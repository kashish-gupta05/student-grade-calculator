# Student Grade Calculator 🧮🐍

A simple Python project that calculates a student's total marks, percentage, and grade.

## Features

- Takes student's name
- Takes marks of 5 subjects
- Calculates total marks
- Calculates percentage
- Displays grade

## Grading System

| Percentage | Grade |
|------------|-------|
| 90% - 100% | A+ |
| 80% - 89% | A |
| 70% - 79% | B |
| 60% - 69% | C |
| 50% - 59% | D |
| Below 50% | F |
